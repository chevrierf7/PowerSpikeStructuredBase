# HUD Rules

Direction interne pour le HUD de Shuttle Rush.

- Le HUD doit viser un rendu anime/esport arcade.
- Utiliser des formes angulaires.
- Utiliser les couleurs issues des `PlayerProfile`.
- Mettre le serveur en valeur.
- Animer le score au changement.
- Afficher un point marque avec un flash leger.
- Prioriser la lisibilite en match.
- Eviter un rendu debug ou application de score.
